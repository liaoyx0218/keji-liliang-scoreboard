# 小组互加与老师加分设计

**日期：** 2026-09-26  
**项目：** keji-liliang-scoreboard  
**状态：** 已批准（对话确认 §1–§5）  
**前置：** [公开课小组积分赛系统设计](./2026-09-17-keji-liliang-scoreboard-design.md)

## 1. 目标与范围

在现有「能量榜」上扩展加分入口：组间互加、老师给指定组加分；**同一能量分、同一大屏排名**。

### 要做的

- 学生端保留「能量 +2」（给本组）
- 学生端可给**其他组**每次 +2（白送：对方 +2，本组不变；可反复）
- 教师大屏点某个组气泡，给该组 +2
- 大屏加分须有可见反馈：该组旁跳出「+2」并上浮淡出，分数同步更新
- 三种加分都进入 `Group.score`，排名规则不变（分数降序，同分组号升序）

### 不做的（本版）

- 分来源分栏（自加 / 互评 / 师评分开展示）
- 互评次数上限、转赠扣分、自定义分值
- 课中「自加/互评模式」开关
- 评价问卷、星级等复杂表单
- 教师登录 / 权限系统（信任模型与现网一致：持有 URL 即可操作）

### 成功标准

1. 一组给另一组 +2 → 大屏对方立刻涨分，本组不变  
2. 老师点组气泡 → 该组立刻 +2，并播弹出「+2」动效  
3. 学生「给我组」自加仍可用  

## 2. 架构与数据流

在现有 Session + Group.score + WebSocket 排行榜广播上扩展，不拆新系统。

```
学生端 /s/:sessionId
  ├─ 页签「给我组」→ POST 对本组 score (+2, source=self)
  └─ 页签「给别组」→ POST 对其他组 score (+2, source=peer, fromGroupId=本组)

教师大屏 /t/:sessionId
  └─ 点气泡 → POST 对目标组 score (+2, source=teacher)
                    ↓
            SessionStore 原子 score += 2
                    ↓
            WebSocket 广播完整排行榜
```

### 服务端约定

- **API**：扩展现有 `POST /api/sessions/:sessionId/groups/:groupId/score`；请求体可选字段：
  - `source`: `"self"` | `"peer"` | `"teacher"`（缺省按 `"self"`，兼容现网自加）
  - `fromGroupId`: 仅 `source=peer` 时必填；须为本场存在的组，且 ≠ 路径中的目标 `groupId`
- 统一对目标组原子 `score += 2`，成功后广播排行榜
- **师加**：大屏持有 `sessionId` 即可；不要求额外凭证（与现网大屏操作一致）
- `Group.score` 仍是唯一展示分；本版**不要求**大屏展示加分来源。不加分事件持久化（YAGNI）
- 清空能量 / 隐式初始化：行为与现网相同；组列表变化后互加目标随之变化
- 学生端「给别组」列表数据：用现有排行榜快照/WS 即可（过滤掉本组）

## 3. 页面交互

### 3.1 学生端（页签布局）

- **给我组**：组名、当前能量、超大「能量 +2」（现有行为）
- **给别组**：其他组列表，每行组名 +「+2」；白送加分
- 仅有本组时：「还没有其他组」空态
- 失败策略：不做乐观更新；文案「没加上，再试一次」（与现网一致）
- 成功时可有轻量「+2」反馈（可选，非大屏级动效硬性要求）

### 3.2 教师大屏

- **点气泡立刻 +2**，无确认对话框
- **加分动效**：被点组旁跳出「+2」，上浮淡出；分数同步更新
- 连点同一组：每次各请求一次 +2，每次播动效（允许短暂叠字）
- 仅请求成功后播动效；失败不播、分不涨
- 现有颁奖、清空能量（长按）、隐式初始化保留不变

## 4. 异常与边界

| 情况 | 行为 |
|------|------|
| 断网或请求失败 | 提示「没加上，再试一次」；无动效；分数不变 |
| 场次已重置 / 目标组不存在 | 学生端走现有「本场已重新开始，点一下重新加入」；大屏空榜 |
| 互加 from === to 或 from 无效 | 服务端拒绝 |
| 「给别组」无其他组 | 空态文案 |
| 持有学生链接 | 可自加与互加（现网信任模型） |
| 持有大屏链接 | 可师加与现有教师操作 |

## 5. 测试要点

### 服务端单测

- 自加 / 互加（白送、from ≠ to）/ 师加 → score 正确 +2  
- 互加 from === to 或无效 from → 拒绝  
- 重置后对旧组加分 → 失败  

### 验收手测

1. 学生「给我组」自加 → 大屏本组涨分  
2. 学生「给别组」给另一组 +2 → 大屏对方涨、本组不变  
3. 大屏点气泡 → 立刻 +2 + 弹出动效  
4. 断网点加分 → 失败提示、无动效、分不涨  
5. 隐式初始化后学生需重加；互加列表随新组重建  

## 6. 与现网关系

- 不改变创建页、二维码、一设备一组、`localStorage` 绑定与 `resetAt` 恢复规则  
- 不改变大屏排名算法与标题语境（科技力量大 · 小组能量榜）  
- 本设计是能量榜的加分入口扩展，不是独立评价子系统
