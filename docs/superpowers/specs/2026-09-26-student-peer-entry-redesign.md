# 学生端小组互评入口重做设计

**日期：** 2026-09-26  
**项目：** keji-liliang-scoreboard  
**状态：** 已批准（对话确认：方案 1 + 全屏切换；视觉由实现侧按现网科技风打磨）  
**前置：** [小组互加与老师加分设计](./2026-09-26-peer-teacher-scoring-design.md)

## 1. 目标与范围

去掉学生端「给我组 / 给别组」页签，恢复以自加为主的主界面，并增加「小组互评」入口进入全屏互评列表。

### 要做的

- **主界面**：组名、能量、超大「能量 +2」（自加）；其下（或等价次要位置）放置 **「小组互评」** 按钮
- **互评界面**：全屏切换（非弹层）；顶部 **「返回」** 回主界面；其他组列表每行 +2（白送，可反复）
- 空态：「还没有其他组」
- 失败：不做乐观更新；文案「没加上，再试一次」
- API / 大屏师加 / 清空与重置：**不变**

### 不做的

- 改加分规则、次数上限、转赠、登录
- 弹层互评、页签方案
- 老师端改版

### 成功标准

1. 主界面一眼是大「能量 +2」，不靠页签切换自加  
2. 点「小组互评」→ 全屏列表可给别组 +2 → 「返回」回主界面  
3. 自加与互加行为与现网 API 一致  

## 2. 交互

```
主界面 (view=home)
  ├─ 能量 +2 → source=self
  └─ 小组互评 → view=peer

互评界面 (view=peer)
  ├─ 返回 → view=home
  └─ 对其他组 +2 → source=peer, fromGroupId=本组
```

- 默认 `view=home`
- 互评界面可保留本组名作弱提示（非必须）
- WS / leaderboard 仍用于刷新本组能量与互评列表；重置逻辑不变

## 3. 视觉方向（实现侧定稿）

用户无强偏好，要求「好看」。约束：

- **延续** 现有学生端科技风（`StudentPage` / `theme`：深色底、cyan/coral 强调、大触控自加按钮）
- **主次**：自加按钮视觉权重最高；「小组互评」为次要 CTA（对比度够点、但不抢主按钮）
- **互评列表**：清晰行高与 ≥44px 触控的 +2；避免页签式顶栏
- 不引入新设计系统或无关装饰堆砌

## 4. 与现网关系

- 替换页签 UI；复用 `addScore(..., { source, fromGroupId })`
- README 若仍写「页签：给我组 / 给别组」，改为「主界面自加 + 小组互评」

## 5. 测试要点

1. 主界面自加 → 本组涨分  
2. 进互评给另一组 +2 → 对方涨、本组不变；返回后仍在主界面  
3. 仅一组时互评空态  
4. 失败提示与 needRejoin 路径不变
