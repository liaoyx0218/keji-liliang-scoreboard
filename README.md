# 科技力量大 · 小组积分赛

课堂小组「能量」积分榜：教师大屏 + 学生扫码/链接加分。

## 安装

```bash
npm install
```

## 开发

终端 1 — 后端（默认 `http://localhost:3000`）：

```bash
npm run dev -w server
```

终端 2 — 前端（Vite，代理 `/api` 与 `/ws`）：

```bash
npm run dev -w client
```

浏览器打开 Vite 提示的地址（一般为 `http://localhost:5173`）。

### 局域网 / 公开课

手机需与教师电脑访问同一后端。开发时可让 Vite 监听局域网：

```bash
npm run dev -w client -- --host
```

用本机局域网 IP 打开创建页，将**学生端二维码/链接**放进课件；大屏用「打开大屏」或 `/t/:sessionId`。

生产：先 `npm run build`，再 `npm run dev -w server`（或 `node` 启动 `server/src/index.ts`），同一端口同时提供 API 与打包后的前端。

## 验收清单（设计 §9）

1. 大屏无二维码，可见空榜或等待态。
2. 创建页得到唯一学生链接/码；设备 A→组一，设备 B→组二。
3. 组一点 +2 → 本地与大屏均为 2 且排序正确；连点累加。
4. 设备 A 刷新后仍为组一，分数保留。
5. 隐式初始化后大屏清空；旧端提示重置；再加入从组一计；课件码仍可用。
6. 断网点 +2 有失败提示且分数不误增。

手测：2～3 部手机 + 一台上大屏电脑走完以上步骤。

## 教师大屏操作说明

- **颁发科技小达人**：按能量榜前三名颁奖（弹层动画）。
- **长按 3 秒清空能量**：仅分数归零，组保留，学生无需重新扫码。
- **隐式初始化**（角落小点连点 3 次）：清空整场并删组，学生需重新加入。
