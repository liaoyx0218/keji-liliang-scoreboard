# 科技力量大 · 小组积分赛

课堂小组「能量」积分榜：教师大屏 + 学生扫码/链接加分。

- **学生端默认**：只给本组「能量 +2」
- **教师「小组互评」**：学生端进入全屏互评列表给别组 +2（可返回主界面自加）；再点一次结束互评
- **教师「心愿卡」**：学生语音说心愿（阿里云听写），汇总到心愿墙（一组可多条）
- **教师「手抄报」**：学生编辑预填文案，调用豆包 Seedream 生成手抄报，大屏手抄报墙投屏
- 心愿 / 互评 / 排序 / 手抄报互斥（开一个会自动关其他）

## 安装

```bash
npm install
```

复制环境变量模板，填入阿里云智能语音交互密钥（可与 `desktop-digital-human` 的 `.env` 相同三项），以及火山方舟文生图密钥：

```bash
cp .env.example .env
# ALIYUN_AK_ID / ALIYUN_AK_SECRET / NLS_APP_KEY
# ARK_API_KEY / ARK_IMAGE_MODEL（手抄报生图，见火山方舟控制台）
```

## 开发

终端 1 — 后端（默认 `http://localhost:3000`）：

```bash
npm run dev -w server
```

终端 2 — 前端（Vite，代理 `/api` 与 `/ws`）：

```bash
npm run dev -w client
```

浏览器打开 Vite 提示的地址（一般为 `http://localhost:5173`）。

### 局域网 / 公开课

手机需与教师电脑访问同一后端。开发时可让 Vite 监听局域网：

```bash
npm run dev -w client -- --host
```

用本机局域网 IP 打开**开课台**（路径见下，勿写进学生课件），将**学生端二维码/链接**放进课件；大屏用「打开大屏」或创建后给出的 `/host/:sessionId/:teacherKey`（含密钥，勿泄露）。

生产：先 `npm run build`，再 `npm run start -w server`（或 `tsx` 启动），同一端口同时提供 API 与打包后的前端。

### 开课台与教师大屏地址

- **开课台**（创建本场）：`/desk/kl-open-8f2c` —— 仅教师收藏，首页 `/` 不会进入开课。
- **教师大屏**：`/host/<sessionId>/<teacherKey>` —— 密钥不在学生链接里；把学生的 `/s/...` 改成 `/t/...` 进不了大屏。
- **学生端**：`/s/<sessionId>`

### HTTPS（心愿语音必读）

平板/手机在非 `localhost` 的 **HTTP** 下通常无法调用麦克风。公开课若要用「按住说话」，请用 **HTTPS** 访问。现网可用自签：`https://47.99.244.23/`（首次需点「继续访问」）。

## 教师大屏操作说明

- **点组气泡**：给该组能量 +2（弹出 +2 动效）。
- **颁发科技小达人**：按能量榜前三名颁奖。
- **小组互评**：下发或收回学生端互评界面。
- **心愿卡**：开启或关闭心愿提交；**心愿墙 / 能量榜** 切换大屏视图。
- **手抄报**：开启后学生端编辑预填模板并生成 AI 手抄报；大屏「成果墙」可切到手抄报墙投屏。
- **心愿墙点卡片**：满屏放大投屏。
- **清空能量**（长按 3 秒）：仅分数归零，组与心愿保留。
- **隐式初始化**（角落小点连点 3 次）：清空整场并删组与心愿，学生需重新加入。
